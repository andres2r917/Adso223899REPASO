TALLER PRACTICO

Atributos principales del (form) y su función 1. Action Indica a dónde se envían los datos del formulario cuando el usuario presiona el botón de enviar. Especifica la URL o el archivo que procesará la información. Ejemplo: form action="procesar.php" Significa que los datos se enviarán al archivo procesar.php.
2. Method Define cómo se envían los datos del formulario. Existen dos métodos principales: GET: Envía los datos a través de la URL. La información es visible. Se usa para búsquedas. POST: Envía los datos de forma oculta (no visible en la URL). Es más seguro. Se usa para registros, inicios de sesión y envío de datos importantes. Ejemplo: form method="POST"
3. Autocomplete Permite activar o desactivar el autocompletado del navegador. on → El navegador guarda y sugiere datos escritos anteriormente. off → No guarda ni muestra datos previos. Ejemplo: form autocomplete="off"
4. Target Indica dónde se mostrará la respuesta del formulario después de enviarlo. Valores más usados: self → En la misma pestaña (valor por defecto). blank → En una nueva pestaña. parent → En el marco padre. top → En toda la ventana del navegador. Ejemplo: form target="_blank"
5. Novalidate Desactiva la validación automática de HTML5. Normalmente, el navegador valida campos obligatorios o correos electrónicos antes de enviar el formulario. Si se usa novalidate, el formulario se envía sin validar. Ejemplo: form novalidate
